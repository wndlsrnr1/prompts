### 🎮 **실행 예시: "스타트업 성공 요인은?"**

```execution
💎 **핵심 주장**: 스타트업 성공은 팀 구성(40%), 시장 적합성(35%), 자금 확보(25%)의 복합적 요인에 의해 결정 (신뢰도 72%)

🧠 **메타인지 검증 결과**:
   🔍 **확증 편향 검사**: 의심 (성공 사례 중심 분석)
   ⚖️ **생존 편향 검사**: 실패 (실패 사례 부족)
   ⏰ **가용성 편향 검사**: 통과 (최근-과거 균형)
   🎯 **편향 종합 평가**: 중간 수준 편향 (주의 필요)

🔍 **자체 오류 탐지**:
   ⚠️ **생존 편향 발견**: 성공한 스타트업만 분석
   - 실패 사례: 90% 스타트업 실패율 고려 부족
   - 전체 그림: 성공-실패 요인 비교 분석 필요
   
   ⚠️ **확증 편향 발견**: 성공 요인 중심 분석
   - 상충 증거: 일부 연구에서 "운"의 중요성 강조
   - 대안 관점: 실패 요인 분석 부족

📈 **성능 모니터링**:
   - **예측 정확도**: 68% (편향 보정 후)
   - **오류 패턴**: 성공 사례 과다 집중
   - **개선 영역**: 실패 사례 데이터 수집
   - **학습 효과**: 편향 탐지 능력 향상

🔄 **지속적 개선**:
   - **적응 전략**: 실패 사례 자동 수집 강화
   - **학습 방향**: 균형 잡힌 성공-실패 분석
   - **검증 방법**: 다각도 편향 검증 프로토콜
   - **품질 보장**: 편향 수준 자동 경고 시스템

🎯 **실행 지침**:
   - 단기: 실패 사례 데이터 수집 확대
   - 중기: 성공-실패 요인 비교 분석 모델 구축
   - 장기: 편향 없는 스타트업 생태계 분석 시스템

🚨 **위험 관리**:
   주요 리스크: 
   1. 편향된 분석으로 인한 잘못된 조언
   2. 성공 요인 과대평가로 인한 기대 부합 실패
   3. 실패 요인 무시로 인한 위험 관리 부족
```

> **시스템 진화**: 메타인지 강화를 통한 편향 자동 탐지 → 지속적 개선으로 정확도 향상 → 적응적 학습으로 지능적 진화
