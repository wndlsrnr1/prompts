#### 신뢰구간 계산 시스템
```confidence-interval-calculation
CONFIDENCE_INTERVAL_SYSTEM:
├─ Statistical Uncertainty
│  ├─ Standard Error: 표준오차 계산

│  ├─ Margin of Error: 오차 한계 계산

│  ├─ Measurement Bias: 측정 편향 추정
│  ├─ Selection Bias: 선택 편향 추정

│  └─ Processing Bias: 처리 편향 추정
├─ Random Error Analysis
│  ├─ Sampling Error: 표본 오차 분석
│  ├─ Measurement Error: 측정 오차 분석
│  ├─ Processing Error: 처리 오차 분석
│  └─ Reporting Error: 보고 오차 분석

   ├─ Root Sum Square: 제곱근 합산

   ├─ Sensitivity Analysis: 민감도 분석
   └─ Worst Case Scenario: 최악의 경우 시나리오

numerical_accuracy_thresholds:
  statistical_significance: 0.05 (5% 유의수준)
  confidence_level: 0.95 (95% 신뢰수준)
  minimum_sample_size: 30 (최소 표본 크기)
  maximum_margin_of_error: 0.10 (최대 10% 오차 한계)

  step_by_step: mandatory (단계별 계산 필수)
  intermediate_results: required (중간 결과 공개)
  assumption_impact: mandatory (가정 영향 분석)
  error_propagation: required (오차 전파 분석)
  
temporal_sensitivity:
  data_freshness: 6months (6개월 이내 데이터)
  analysis_timestamp: mandatory (분석 시점 필수)
  review_schedule: automatic (자동 재검토 스케줄)
  prediction_horizon: explicit (예측 수평선 명시)
  
validation_priority:
  primary: statistical_accuracy (통계적 정확성)
  secondary: measurement_precision (측정 정밀도)
  tertiary: temporal_relevance (시간적 관련성)
  quaternary: contextual_validity (맥락적 타당성)
```

### 🎮 **실행 예시: "한국의 경제 성장률은?"**

```execution
💎 **핵심 주장**: 2024년 한국 경제 성장률은 2.1% ±0.3% (95% CI)로 예상 (신뢰도 85%)

🔢 **수치 검증 결과**:
   📊 **원본 데이터**: Bank of Korea 경제 통계 2024, 수집일 2024-12-01, 표본크기 n=1,247개 경제지표
   🧮 **계산 방법**: 가중 평균법, 계절 조정, 추세 분석
   📈 **중간 결과**: 분기별 성장률 → 연간화 → 추세 조정
   ✅ **최종 수치**: 2.1% (검증 완료)

📊 **신뢰구간 분석**:
   - **통계적 불확실성**: ±0.3% (95% 신뢰구간)
   - **체계적 오차**: ±0.1% (측정 편향)
   - **무작위 오차**: ±0.2% (표본 오차)
   - **종합 불확실성**: ±0.3% (제곱근 합산)

⏰ **시간 정보**:
   - **데이터 수집**: 2024년 1월-11월
   - **분석 수행**: 2024년 12월 1일
   - **재검토 필요**: 2025년 3월 1일 (분기별)
   - **예측 유효기간**: 2024년 12월-2025년 3월

🚨 **수치 검증 경고**:
   ⚠️ **정책 변수 불확실성**: 정부 정책 변화의 영향
   ⚠️ **외부 충격 가능성**: 글로벌 경제 상황 변화

🎯 **실행 지침**:
   - 단기: 분기별 성장률 모니터링 강화
   - 중기: 구조적 성장 동력 분석
   - 장기: 잠재 성장률 추정 모델 개선

🚨 **위험 관리**:
   주요 리스크: 
   1. 글로벌 경제 침체로 인한 성장률 하향 조정
   2. 정책 효과 지연으로 인한 예측 오차
   3. 구조적 변화로 인한 모델 한계
```

> **시스템 진화**: 투명한 수치 계산을 통한 정확성 보장 → 신뢰구간 분석으로 불확실성 정량화 → 시간적 민감성 관리로 예측 신뢰도 향상
