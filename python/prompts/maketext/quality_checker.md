## 📝 **프롬프트 본문**

```
# ✅ Quality Checker: Structured Learning Material Verification

## 🎯 **검증 목표**
생성된 학습 자료가 what_is_ai 폴더의 품질 기준을 충족하는지 확인하여 다음을 검증하세요:

1. **완성도 검증**: 모든 주요 주제 포함 여부
2. **일관성 검증**: 포맷팅, 스타일, 구조의 일관성
3. **접근성 검증**: 학습자 친화적 설계
4. **상호 참조 검증**: 모듈 간 연결 및 크로스 레퍼런스

## 🏗️ **검증 기준**

### **1. 완성도 검증 (95% 이상)**

- [ ] 00_README_Index.md 존재 및 완성
- [ ] 학습 경로 시각화 포함
- [ ] 난이도별 분류 완료
- [ ] 모듈 구성 계획 명시
- [ ] 학습자별 가이드 제공

#### **모듈 완성도**

- [ ] 체계적 섹션 구성
- [ ] 영어 어휘 지원 통합
- [ ] 실용적 예시 포함

#### **어휘 가이드 완성도**

- [ ] 정의 및 예시 제공
- [ ] 관련 용어 연결

### **2. 일관성 검증 (90% 이상)**

#### **포맷팅 일관성**

- [ ] 영어 어휘 지원 섹션 형식 일치
- [ ] 코드 블록 및 예시 형식 통일
- [ ] 시각적 요소 (이모지, 표) 일관성

#### **스타일 일관성**
- [ ] 어조 및 톤의 일관성
- [ ] 기술 용어 사용의 일관성
- [ ] 설명 수준의 일관성
- [ ] 예시 스타일의 일관성

#### **구조 일관성**
- [ ] 모듈 간 구조의 일관성
- [ ] 섹션 구성의 일관성
- [ ] 앵커 링크 형식의 일관성
- [ ] 크로스 레퍼런스 형식의 일관성

### **3. 접근성 검증 (85% 이상)**

#### **학습자 친화성**
- [ ] 난이도별 설명 수준 적절

- [ ] 실용적 예시 제공

#### **영어 어휘 지원**
- [ ] 기술 용어 정의 완성
- [ ] 발음 가이드 포함
- [ ] 사용 예시 제공
- [ ] 관련 용어 연결

#### **시각적 요소**
- [ ] 이모지 활용 적절
- [ ] 표 및 다이어그램 활용
- [ ] 시각적 구분 요소 활용
- [ ] 가독성 향상 요소

### **4. 상호 참조 검증 (80% 이상)**

#### **모듈 간 연결**
- [ ] 모듈 간 링크 연결 완료
- [ ] 관련 개념 크로스 레퍼런스
- [ ] 학습 경로 안내
- [ ] 종합 가이드 통합

#### **내부 참조**

- [ ] 목차와 섹션 연결
```
