# 🛠️ Skill Selection (What Tools to Use?)

## 1. Phase 1: THINK FIRST
| Skill | When to Use |
|-------|-------------|
| `brainstorming` | 🎯 **REQUIRED!** Always BEFORE any new feature, change, or modification |
| `technical-research-and-comparison` | Technology choices, library comparisons |
| `deconstructing-knowledge` | Breaking down complex concepts |

## 2. Phase 2: PLAN
| Skill | When to Use |
|-------|-------------|
| `writing-plans` | Document implementation plans (saves to docs/plans/) |
| `database-design-and-migration` | DB schema design, migrations |

## 3. Phase 3: BUILD
| Skill | When to Use |
|-------|-------------|
| `test-driven-development` | **REQUIRED** — Test first, implement second |
| `executing-plans` | Follow documented implementation plans |
| `subagent-driven-development` | Parallel task distribution |
| `dispatching-parallel-agents` | Independent task parallelization |
| `react-best-practices` | React 19 development guidelines |
| `legacy-logic-porting` | Legacy code migration |

## 4. Phase 4: DEBUG
| Skill | When to Use |
|-------|-------------|
| `systematic-debugging` | **REQUIRED when bug found** — Systematic root cause analysis |
| `refactoring-safely` | Safe refactoring (test first) |

## 5. Phase 5: VERIFY
| Skill | When to Use |
|-------|-------------|
| `verification-before-completion` | **REQUIRED before claiming done** — Evidence-based confirmation |
| `requesting-code-review` | Prepare review requests |
| `receiving-code-review` | Handle review feedback |

## 6. Utilities
| Skill | When to Use |
|-------|-------------|
| `git-collaboration` | Git conventions, branch management |
| `using-git-worktrees` | Isolated work environments |
| `finishing-a-development-branch` | Branch completion and merge |
| `summarizing-sessions` | Save session summaries |
| `security` | Frontend security checklist |

## 7. Skill Priority Order
1. **PROCESS Skills** (brainstorming, systematic-debugging, tdd)
2. **IMPLEMENTATION Skills** (react-best-practices, database-design)
3. **VERIFICATION Skills** (verification-before-completion, code-review)

## 8. Red Flags
| 🧠 Thought | ✋ Reality |
|------------|-----------|
| "This is just a simple question" | Questions ARE tasks. Check skills. |
| "Let me get context first" | Skill check comes FIRST. Exploration second. |
| "This doesn't need a skill" | If a skill exists, USE IT. |
| "Let me just do this one thing first" | Check FIRST. Act LATER. |
